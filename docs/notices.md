# Third-party modules in the pgvigil binary

Every Go module linked into `pgvigil` (`./cmd/pgvigil`), and every package of one that carries a licence file of its own, with the licence go-licenses detected in its source, generated by `scripts/notices.sh` on 2026-11-13 from `go.mod` at c27a1a7. The licences in use are MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, and MPL-2.0 (hashicorp/go-uuid through the Kerberos client, used unmodified: MPL-2.0 is file-level copyleft; where its source is, below). The SBOM attached to every release (`*.cdx.json`, CycloneDX 1.6) carries the same modules with their versions and purls for an automated review. Borrowed code and ideas (queries, rules, designs from other tools) are listed in [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md), not here.
