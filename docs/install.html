Install

Try it on a demo fleet first, then install the collector as a service. Nothing is installed on the PostgreSQL and SQL Server servers you watch.

Try the demo

Download pgvigil from the latest release and point it at the bin folder of any PostgreSQL install. One command builds a throwaway demo fleet of PostgreSQL and SQL Server servers with a week of history and opens it in its own window. No Docker. Tested on Linux; on Windows (a portable PostgreSQL, no admin rights) not tested yet.

pgvigil demo -pgbin <a PostgreSQL bin folder> -serve -open

Install as a service

One line fetches the release, checks its checksum and installs the collector as a service. Run it again to upgrade.

# Linux: a system account and a systemd unit
curl -fsSL https://pgvigil.com/install.sh | sh

# Windows, in an elevated PowerShell: a service under NT SERVICE\pgvigil
irm https://pgvigil.com/install.ps1 | iex

Set it up by hand

  1. Download the file for your platform from the latest release and check it against SHA256SUMS; the README shows the two commands.
  2. Create an empty database on a PostgreSQL 13 or later server for pgvigil's history (tested on 13, 16 and 18), and copy pgvigil.example.yaml. Keep passwords in the environment or a file, not in the config: pgvigil refuses an inline one for SQL Server and for the actions and EXPLAIN logins, not for a PostgreSQL server's own login or the repository.
  3. Create the tables, the logins and the first web user. The login that owns pgvigil's database needs CREATEROLE: migrate creates pgvigil's own roles.
  4. Start the collector and the web page, over HTTPS with pgvigil cert or your own certificate.
pgvigil migrate -config pgvigil.yaml
pgvigil roles                       # prints the CREATE ROLE statements to run
pgvigil user add admin -config pgvigil.yaml
pgvigil run -config pgvigil.yaml
pgvigil serve -config pgvigil.yaml -listen 0.0.0.0:8443 -tls-cert pgvigil.crt -tls-key pgvigil.key

Adding servers, the SQL Server login, the cloud settings and every option are in the documentation. For a site with no internet access, follow the offline install. To move an installed pgvigil to a new release, follow the upgrade in its order.
