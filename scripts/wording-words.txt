# The wording walk's words: each one names a thing only one engine has under that name, so on a page of the other
# engine it is a red (scripts/wording-match.mjs; the design: a word is listed when the other engine has no such thing
# under that name). A row: engine | word | pattern | source.
#   engine   the engine that owns the word: sqlserver or postgres (the word is a red on the other engine's pages)
#   pattern  empty: the word itself, whole words, without case; 'cs:' first: with case (an abbreviation); else a
#            JavaScript regular expression (whole words are the pattern's own business), matched without case
# Left out on purpose (both engines own them, or plain English that ordinary text holds): Backup FULL and Backup DIFF
# (pgBackRest's backup types are full, diff and incr), Log Shipping (PostgreSQL's docs: 'Log-Shipping Standby
# Servers'), Identity Columns (PostgreSQL 10+), Logins / Failed Logins (a role's LOGIN attribute), Log Space, File
# Space, % Max Size, Kill, Server Services, Jobs, Backups, Deadlocks, Waits, Blocking, Sequences, Indexes, Roles,
# Schema, Statistics; bloat alone (SQL Server's Memory page: 'plan cache bloat'); Entra (Azure Database for
# PostgreSQL authenticates Entra users too); Windows account (PostgreSQL on Windows: SSPI).
